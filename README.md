## How it works

`main.py` (Python 3 standard library only, no network, no fonts on disk)
draws the whole image procedurally — a hand-drawn 5x7 bitmap font, flat
vector illustrations, a simplified world map — and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`). It is fully
deterministic: every run writes the same bytes.

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is a 1024x1024 PNG, well under the 1 MiB limit.
